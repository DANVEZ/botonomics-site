Botonomics · 机器人价值罗盘（V2）—— 使用说明
==================================================

一、怎么打开
------------
双击 index.html，用浏览器打开即可。
不需要安装、不需要联网、不需要服务器。整个网页就是一个文件。

如果双击后是记事本打开，右键 →「打开方式」→ 选 Chrome / Edge / Safari。

二、它是干什么的
----------------
给酒店 / 商场 / 医院 / 餐饮的后勤采购，以及 Keenon 销售与代理：
选国家 → 选场景 → 自动出 TSWC 组合 → 当场算出钱（投入、省下的人工、回本月数、三年净收益）。

四类场景：
  1. 清洁      C30 / C40 / C55
  2. 酒店配送  W3
  3. 餐饮配送  T8 / T9 / T10 / T11
  4. 组合推荐  多机型自动搭配

三、基本操作
------------
1) 顶部选国家 → 币种、汇率、行业人工成本、三档参照条自动带出。
2) 左栏填参数，右栏立刻出结果：读数窗 → 官方基准复现 → 关键指标 → 每月钱去哪 → 累计净收益曲线 → 数据来源。
3) 右上角可切换语言：中文 / English / Deutsch / Italiano / Français / Español。
4) 右上角「打印 / 存 PDF」出 A4 一页版，可直接发给客户。

四、几个小提示
--------------
· 联网时页面会自动取实时汇率；断网或取数失败会自动用内置快照，照样能算。
· 汇率只影响"展示换算"，不影响 ROI 计算本身（ROI 始终按基准币种算）。
· 数字都可以手改。改过的币种会标「手动」，之后不会被自动刷新覆盖。
· 组合场景里勾选痛点，会自动追加机型；窄道/老楼可把 T10 换成 T11（49cm 窄身）。

五、链接参数（做演示或截图时好用）
----------------------------------
  index.html?lang=de          指定语言（zh / en / de / it / fr / es 或对应国家码）
  index.html?country=FR       指定国家
  index.html?mode=combo       直接进组合推荐
  index.html?theme=dark       指定主题（light / dark / auto）
  index.html?mode=combo&combo=hospital&rooms=300&area_m2=20000&floors=8&applied=1

六、数据口径（重要）
--------------------
· 人工成本：Eurostat lc_lci_lev（2025）+ 全经济中位数工资（SES 2022）
· 最低工资：Eurostat earn_mw_cur（2026-S2）；英国取 gov.uk National Living Wage
· 汇率：jsDelivr currency-api（ECB 口径）→ open.er-api.com → ECB 官方 XML → 内置快照
· 部分国家（GB / TR 等）缺权威数据时，页面显示「[待补]」要求手填，不印假数；
  带 ⚠ 的国家表示该行业数据异常已回退为工资估算 —— 对外报价前请自行核对。
